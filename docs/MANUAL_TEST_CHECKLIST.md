# Ручная проверка в браузере

## Вход
- [ ] Без входа любая страница открывает `/login`
- [ ] Неверный пароль показывает ошибку, ссылки на регистрацию нет
- [ ] Выход возвращает на `/login`

## Постановщик
- [ ] Видит все объекты и все задачи; фильтр «На проверке» работает
- [ ] Создаёт, редактирует объект; объект с задачами удалить нельзя (понятная ошибка), пустой можно
- [ ] Создаёт задачу в карточке объекта: пустое название и пустой исполнитель не проходят
- [ ] В статусах «Новая», «В работе», «На доработке» нет кнопок смены статуса
- [ ] На проверке есть «Принять» и «Вернуть на доработку»
- [ ] Возврат без комментария не проходит; с комментарием комментарий виден в истории
- [ ] У принятой задачи нет «Редактировать» и нет кнопок статуса
- [ ] Удалённая задача исчезает из списков

## Исполнитель
- [ ] Сразу попадает в «Мои задачи», видит только свои задачи и объекты
- [ ] Нет кнопок создания, редактирования, удаления
- [ ] «Взять в работу» → «Отправить на проверку»: кнопки меняются, история растёт
- [ ] На проверке и после принятия кнопок нет
- [ ] После возврата видит комментарий и снова может взять в работу
- [ ] Чужая задача по прямой ссылке (скопировать у второго исполнителя) показывает «Не найдено»
- [ ] Чужой объект по прямой ссылке показывает «Не найдено»

## Общее
- [ ] Две вкладки: действие во второй, устаревшей, показывает ошибку, а не ломает страницу
- [ ] Телефонная ширина: нижнее меню, нет горизонтальной прокрутки, диалоги помещаются
- [ ] Тёмная тема читается, после перезагрузки сохраняется
- [ ] В DevTools нет ошибок hydration
